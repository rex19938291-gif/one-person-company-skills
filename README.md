# 一人公司 AI 協作 Skill 包

這是《一人公司五週教練課 2.0｜AI Agent 協作版》課程用的 Skill 集合。

每一個資料夾就是一個 Skill。你不需要看懂裡面的內容，也不需要自己安裝——
**把資料夾的網址複製起來，貼給你的 AI Agent，請它照著做就好。**

## 怎麼用

在你的 Agent（Claude Code、Codex 或其他支援 Agent Skills 的工具）裡貼上這段話，把網址換成你要用的那一個：

```
請幫我安裝這個 Skill：
https://github.com/rex19938291-gif/one-person-company-skills/tree/main/skills/vsl-webinar-script
安裝完成後，用它幫我產出 VSL 腳本。
```

Agent 會自己把內容抓下來、放到正確的位置，然後照著執行。

## 幾件要先知道的事

1. **這些 Skill 只是把做法寫清楚給 Agent 看，它們不會自己連上你的網站或廣告帳戶。**
   要連線是另外一件事，課程第 0 週會教。
2. **凡是會動到你正式網站的操作，先備份。** Skill 裡都有寫，但請你自己也養成習慣。
3. **Skill 不會幫你決定價格、名額、優惠期限或任何承諾。** 那些是你的生意決定。
4. 內容會持續更新，建議照著課程進度重新拉一次最新版。
