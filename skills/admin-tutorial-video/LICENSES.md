# 音樂授權紀錄範本

本技能不附任何音樂檔，也不授予任何曲目的使用權。以下是專案要填寫的格式，未填寫前不代表已取得授權。

| 欄位 | 下載當時記錄 |
|---|---|
| 曲名與作者 | 待填 |
| 來源頁 | 待填：曲目的實際來源頁 |
| 授權頁 | https://pixabay.com/service/license-summary/ （選其他來源時替換） |
| 下載日期與條款版本 | 待填 |
| 本機檔名與下載證明 | 待填：留在自己的專案，不納入公開技能 |
| 是否標示 Content ID | 待填；未確認不可寫「沒有」 |
| 條款原文摘錄 | 待填與本次使用直接相關的短摘錄，並保留當時可合法保存的條款副本 |
| 本次使用／加工範圍 | 待填：剪接、音量調整、接長、混音及發布平台 |

Pixabay 授權摘要的短摘錄：

> Use Content for free
>
> Modify or adapt Content into new works

來源：[Pixabay Content License Summary](https://pixabay.com/service/license-summary/)。完整限制以來源當時條款為準；免費、免標註、可加工不代表可單獨轉售音樂或忽略其他權利。網站擋自動下載時，請你親自下載。Content ID 曲目可能引發 YouTube 聲明，保留來源及下載證明；不能保證聲明自動解除。
