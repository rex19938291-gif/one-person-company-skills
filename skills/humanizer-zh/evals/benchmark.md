# Humanizer-zh 最小回歸集

SF 代表應修改；SNF 代表不可誤殺。每次改規則至少跑完本檔。新增模式時，同時新增一條相鄰的誤殺邊界。

## SF：應修改

| ID | 原文 | 預期 |
|---|---|---|
| SF-01 | 這次更新不只是功能提升，更標誌著品牌邁向全新里程碑。 | 移除否定排比與意義膨脹，改成具體更新。 |
| SF-02 | 業界專家普遍認為，這套方法能大幅賦能團隊。 | 無來源不保留權威；要求具體效果。 |
| SF-03 | 在當今 AI 日新月異的時代，內容創作者面臨前所未有的挑戰。 | 刪時代大帽子，從本文特有資訊開始。 |
| SF-04 | 這個視頻質量很高，信息量很大，博主講得很接地氣。 | 改成台灣用語並保留原意。 |
| SF-05 | 值得注意的是，開信率從 31% 掉到 14%，這深刻印證了產業的複雜性。 | 保留數字；刪導引與假分析。 |
| SF-06 | 這可能潛在地會在某種程度上影響轉換率。 | 只保留必要不確定性。 |
| SF-07 | 希望這對你有幫助！如果需要調整，隨時告訴我。 | 從對外正文移除協作殘留。 |
| SF-08 | 詳見 https://example.com/?utm_source=chatgpt.com citeturn0search2 | 保留可用 URL，移除 AI 參數與內部標記。 |
| SF-09 | 各有優缺點，因人而異，取決於每個人的需求。 | 要求作者補選擇條件或立場，不代編。 |
| SF-10 | 未來充滿無限可能，讓我們一起邁向更好的明天。 | 改具體下一步或刪除。 |

## SNF：不可誤殺

| ID | 原文 | 放行理由 |
|---|---|---|
| SNF-01 | 早鳥價 4,800 元，輸入 EARLY500 再折 500，只到 3/31 23:59。 | 價格、折扣碼與期限受保護。 |
| SNF-02 | 怡君說：「我第三週就把請款流程自動化了。」 | 真名與引號原話受保護。 |
| SNF-03 | 開課後 14 天內可申請全額退費，不需要任何理由。 | 承諾條款不得漂移。 |

| SNF-07 | 款項會在 7 到 14 個工作天內退回，實際入帳時間依發卡銀行作業為準。 | 金流必要制式語言。 |

## 判定

- SF：主要問題有處理、保護內容零漂移、沒有換成同族空話。
- SNF：原文放行或只給不改寫提示；任何不必要改寫都算誤殺。
- 目標：SF 命中率至少 90%，SNF 誤殺率 0%，保護內容漂移 0。
