不要逐字硬換。「接地氣、抓手、打法、公眾號」須依語境重寫；中國產品名、平台名與受訪者原話照原文。

## 語境詞

- 「優化」若連著具體技術動作與指標可保留；空泛的「優化體驗」要說改了什麼。
- 「數據」與「資料」依領域選擇；分析報告可用數據，一般商務可用資料。
- 技術圈合理使用「用戶端、文件、lazy load」等術語時，不為台灣化而破壞行業語意。
- 被討論的詞不算使用，例如「我決定戒掉『賦能』」。
- 作者刻意玩梗可保留。

## 標點與語感

- 中文句使用全形「，。：；！？「」『』（）、」；URL、程式碼與英文句除外。
- 第一層引號用「」，內層用『』；書名、篇名用《》〈〉。
- 刪節號用「⋯⋯」或「……」，不用 `...`。
- 數字、百分比、日期與單位維持半形。
- 台灣常用量詞：一支影片、一則貼文、一封信、一支手機。
- 社群可保留自然的「啦、欸、喔」，正式文件不要硬加口語尾詞。
- 縮短翻譯腔長定語；「基於、通過……來」多半可改「依照、用、透過」。

## 動補句型（「V 得住／V 不住」與「扛」）

台灣書面與口語都很少用「V 得住／V 不住」來表達「能不能做到某事」，這組是中國網路與媒體常見的說法，成群出現會讓整篇讀起來不像台灣人寫的。「扛」當作「承擔風險或責任」用時同理，台灣說「承擔」「負責」「自己來」「自己處理」，「扛」多半只用在扛東西或「扛下來」這種完成式。

| 不是台灣說法 | 台灣常用 |
|---|---|
| 管得住／管不住 | 顧得到／顧不到、能幫你確認、管不了 |
| 接得住 | 接得上、銜接得起來、承接得了 |
| 扛得住／扛不住 | 撐得住、承受得了、負擔得起 |
| 兜得住 | 收得起來、圓得回來 |
| 你願意自己扛多少 | 你想自己判斷到什麼程度、有多少事想自己來 |
| 風險自己扛 | 風險要自己承擔 |
| 責任自己扛 | 責任要自己負 |
| 這些都自己扛 | 這些都要自己來 |
| 多扛的這一段 | 多承擔的這一段 |
| 全部由你自己扛 | 就是你要自己處理 |
| 由誰扛 | 由誰負責 |

判斷方式：看到「V 得住／V 不住」先問這個動詞在台灣是不是真的這樣搭。「站得住腳」「守得住」「撐得住」是台灣本來就有的，不要誤殺；「管得住」「接得住」「兜得住」這種把抽象事物當受詞的才是要換的對象。

「扛」單獨出現一次不必動，但一篇文章出現三次以上、而且都在講承擔風險或責任，就要換掉大部分，只留最口語自然的那一兩處。
