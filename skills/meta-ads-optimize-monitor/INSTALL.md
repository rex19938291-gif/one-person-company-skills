# 安裝與第一次設定（給學生或同事）

## 需要準備

| 項目 | 用途 | 說明 |
|---|---|---|
| 支援 Agent Skills 的代理工具 | 執行這套流程 | 例如 Claude Code（需有排程功能）；其他工具需能定時執行並讀寫本機檔案 |
| Meta 廣告帳號存取 | 讀成效、改預算 | 建議用 Meta 官方廣告連接器；或自建的 Marketing API 工具。只給必要的廣告帳號權限 |
| 網站報名資料的唯讀管道 | 交叉核對實收 | 表單外掛的唯讀介面、統計試算表，或網站管理工具；只需筆數，不需個資 |
| Google 試算表（選用） | 紀錄與總覽 | 沒有也可以，改用本機紀錄檔 |
| 通知管道（選用） | 提醒決策者 | 預設只寫待決策佇列；要推送可接 Telegram、Email、Slack 或 LINE 官方帳號 |

**本 skill 不含任何金鑰、權杖或個資**；各種存取權限請在自己的工具設定，不要寫進 skill 或設定檔。

## 第一次設定步驟

1. 安裝 skill：把本資料夾放進代理工具的 skills 目錄（Claude Code 為 `~/.claude/skills/` 或專案的 `.claude/skills/`）。安裝前建議先用你慣用的 skill 安全檢查工具掃描。
2. 讀 `SKILL.md`，照第 0 步做本專案盤點，產出規劃單給決策者確認。
3. 複製 `templates/project-config.template.json` 到專案資料夾，照 `references/10-專案設定檔填寫說明.md` 填好。
4. 建 `docs/待決策佇列.md`（範本在 templates）；在交接檔加入「新主對話接手步驟」段（範本在 templates）。
5. 照 `references/04-排程分工與範本.md` 建兩支排程：操作排程（例如每 10 分鐘）與只讀的回報排程（每天一次）。回報排程每週一另產出漏斗分段診斷（`references/11-漏斗分段診斷.md`），設定檔 `funnel` 區塊要先填好事件名稱與網站實收來源。
6. **在 app 裡把兩支排程的權限設為自動模式**：無人值守時若停在權限提示，排程會卡住。建立後先手動執行一次，確認紀錄、佇列、儀表板都有更新。

## 常見卡點

- **子代理寫入外部服務被擋**：多數代理工具的子代理沒有寫入廣告平台或網站的權限。請讓子代理只寫文案與設定，寫入由排程本身或主對話執行。
- **結果數讀錯**：只認設定檔指定的事件名稱，完全相等比對。
- **換新對話後收不到排程回報**：照 `references/09` 在新對話重設「完成時通知」。
