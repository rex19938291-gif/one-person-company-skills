# 02 目標與預算口徑

## 一定要寫清楚的數字（沒有紀錄就列待決定）

| 項目 | 說明 |
|---|---|
| 結果定義 | 哪個事件算一筆（報名、名單、購買），對應 action_type |
| 目標筆數 | 總數或每場／每期數量 |
| 期間 | 開始日、結束日（排程到期自動停用） |
| 總預算 | 整段期間可花的錢；另設「硬上限」＝總預算 × 0.9 左右，到了就暫停並通知 |
| 每筆成本上限 | 決策者能接受的單筆成本；換素材與降預算的門檻都從它推 |
| 每日預算合計上限 | 可分期設定；成效好時是否可突破要決策者明講 |
| 單一組合每日預算防呆上限 | 避免一次寫錯單位或連續加爆 |
| 每組廣告則數上限 | 例如每組投放中＋審查中最多 5 則 |

## 口徑

- 每筆成本＝花費 ÷ 平台歸因結果數；另列「全部花費 ÷ 網站實收」對照，兩者差距大時先查追蹤。
- 「近 3 日」一律指最近 3 個完整日，不含今天。
- 預算單位：注意幣別最小單位。台幣等無小數幣別寫整數元，不乘 100；寫入後一定讀回確認。
- 活動預算制（CBO）調的是行銷活動的預算；組合預算制調的是廣告組合，先讀清楚再寫。
- 時區以廣告帳號時區為準。

## 門檻推導範例（數字只是示意，實際依專案）

若每筆成本上限 = C：
- 盤中加預算：今天每筆 ≤ 0.8C 且已有 ≥3 筆。
- 換新文案：單則廣告累計花費 ≥ C 仍 0 筆（且曝光 ≥300）。
- 每日結算加預算：近 3 日 ≥6 筆且每筆 ≤ 0.8C。
- 先關素材：近 3 日每筆 > 1.3C 且花費 ≥ 2.4C。
- 停損暫停並請決策者決定：連續 5 個完整日每筆 > 1.6C。
