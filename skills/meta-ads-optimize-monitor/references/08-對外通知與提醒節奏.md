# 08 對外通知與提醒節奏

廣告把人帶進來之後，提醒、通知、感謝頁說的話都要一致，而且「後台看到的」要等於「實際送出的」。

## 一、程式改了提醒文字，後台要自動同步

自寫的外掛或程式，只要會改到後台可編輯的文字、時間或新增提醒項目，一律走「設定版本＋自動遷移」：

1. 設定裡存版本號；每次改預設文字就新增一筆遷移（版本號、要更新的欄位、被視為「沒手動改過」的舊值指紋）。
2. 載入時檢查版本，較舊就先整份備份到帶日期的選項，再逐欄位處理：
   - 欄位還是舊預設值 → 換成新預設；
   - 欄位被人手動客製過 → **不覆蓋**，在後台顯示提示，請人決定；
   - 新增的欄位 → 補進設定。
3. 寫入用「資料庫值仍等於剛讀到的原值才寫」，避免和後台儲存互相覆蓋。
4. 驗收：逐欄位比對「資料庫存的值＝程式讀到的值＝後台頁顯示」，並把每一則實際訊息渲染出來比對。

## 二、對外口徑一致性檢查清單

改任何一個渠道的說法時，其他渠道同一輪一起檢查：

| 渠道 | 檢查什麼 |
|---|---|
| LINE | 時間、連結、場次名稱、價格與期限 |
| 簡訊 | 同上，注意長度截斷 |
| Email | 主旨與內文、按鈕連結、退訂 |
| 行事曆邀請 | 標題、時間、時區、連結 |
| 感謝頁／報名成功頁 | 下一步說明、加 LINE 入口 |
| 表單 | 選項文字、必填說明、成功訊息 |
| 銷售頁與倒數 | 價格、截止時間、名額說法與實際規則一致 |

## 三、直播／講座提醒節奏範本（可依專案調整）

| 時機 | 附不附本場連結 |
|---|---|
| 報名或綁定通知當下：距開播 > 60 分鐘 | 不附（避免太早拿到連結又忘記） |
| 報名或綁定通知當下：距開播 ≤ 60 分鐘或直播中 | 附本場連結 |
| 當天中午提醒 | 不附連結，只提醒時間 |
| 開播前 60 分鐘 | 附本場連結 |
| 開播前 15 分鐘 | 附本場連結 |
| 開播時 | 附本場連結 |

每則都要能從後台看到實際會送出的文字；測試時用測試名單逐場逐渠道渲染比對。
