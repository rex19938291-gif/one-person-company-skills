# SEO Source Boundaries

## First-Party

Google Search Console:

- Actual clicks, impressions, CTR, and average position.
- Best source for migration risk, query/page retention, and current SEO performance.
- Does not prove ChatGPT or Google AI Overview citation.

## External SERP Context

Ubersuggest:

- SERP position checks.
- Competitors and visible ranking pages.
- Keyword ideas, search difficulty, and search intent.
- AI Overview feature presence.
- Estimated traffic or keyword metrics.

Limitations:

- Does not replace GSC performance metrics.
- AI Overview presence is not citation proof.
- If cited/source URLs are absent, do not claim the target was cited.

## AI Visibility / Citation Proof

Citation proof requires a tool output that includes the cited URL/source URL or a controlled logged result that visibly shows the citation.

Acceptable proof:

- Returned citation/source URL from a dedicated AI visibility tool.
- Prompt Explorer result with citations.
- Captured Google AI Overview source list showing the URL.

Not acceptable:

- SERP has an AI Overview block.
- Target ranks near an AI Overview.
- Brand appears in normal organic results.
- A model answer mentions the brand without source URLs when the question asks about citations.
