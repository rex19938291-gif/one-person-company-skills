# SEO 文章口吻與結構規則

我們自己撰寫或大改 SEO 文章時讀這份；合作寫手交來的稿件不套用，保留寫手口吻，只做排版與去 AI 味。口吻與結構分開：口吻照「實作教學型」，結構與關鍵字照「搜尋意圖型」。
**不要模仿網站上既有文章的口吻**；既有文章只拿來找內部連結與避免主題重複。

## 一、口吻：像做過的人帶讀者一起做

| 要這樣寫 | 不要這樣寫 |
|---|---|
| 用「我們」講自己實際做的經驗：「我們選信用卡付款，大約兩天就收到審核通過的信。」 | 第三人稱概論：「許多人想像的智慧家庭，是下班回家大門自動開啟……」 |
| 稱讀者「你」，全文一致 | 「你」「您」混用；結尾突然變成「讓您……」 |
| 步驟寫到能照做：點哪裡、按鈕叫什麼（用「」標出畫面上的字）、填什麼 | 只說「完成設定即可」「依需求選擇」 |
| 數字要有來源與年份：「Nielsen 2020 年統計，12～65 歲有 92% 一週內用過 LINE」 | 「越來越多人」「已逐漸普及」「日新月異」 |
| 給判斷規則：「想觸及越多選 10～15%，想越精準選 1～5%」 | 「各有優勢，需依實際需求挑選」 |
| 寫卡關怎麼辦：「無法套用？有一個可能是你不是管理員，第一種辦法……第二種辦法……」 | 只寫順利的流程 |
| 診斷順序：「成本太高→先查目標→點擊率低就換素材→點擊正常再看頁面」 | 一串並列的「注意事項」 |
| 口語但不油：可用「喔、囉、吧」收尾，結尾可輕鬆一句 | 型錄詞：打造、令人稱羨、一站式、無後顧之憂、量身打造、堅實後盾 |

品牌介紹段落也照這個口吻：講你們實際會做哪幾件事、流程、要多久，不列「七大核心優勢」這種形容詞清單。

## 二、結構：照搜尋意圖排

1. **H1**：主關鍵字放最前面，後面接讀者想要的結果（例：「主關鍵字新手入門！自己做一點都不難」）。
2. **開頭兩段內就回答**：緊接一個問句 H2（「主關鍵字怎麼開始？」），用 3～5 個編號步驟給濃縮版答案，方便被搜尋結果直接引用。
3. **依階段分 H2**：準備 → 實際操作 → 進階 → 看成效／維護。每個 H2 底下的 H3／H4 用「第一步、第二步」或「第一層、第二層」編號。
4. **產品或選項各一個 H3**：每個 H3 就是一個長尾字（例：智慧開關、智慧窗簾），寫用途、挑選重點、價格或規格範圍。
5. **品牌段落放在最後一個教學 H2 之後**，接預約或服務頁的內部連結。
6. **FAQ 放最後**：3～5 題，題目用讀者真的會搜尋的問句；每題答案 2～3 句、單獨看也看得懂。

## 三、關鍵字分配

- 主關鍵字：H1、第一個 H2、開頭第一段、網址代稱、文章分類標籤各出現一次。
- 同義詞要分散：如「智能家居／智慧家居／智慧家庭／智慧住宅」，分到不同 H2、H3 與 FAQ，不要同一段重複堆。
- 長尾字：放在對應意圖的 H3 與 FAQ 題目，例如「舊屋也能做嗎」「需要哪些基礎設備」。
- 內部連結：連到 2～4 篇相關文章，加上 1～2 個轉換頁（預約、服務方案）。

## 四、結構化資料與頁面資訊

- 文章類型用 BlogPosting：headline 只寫文章標題（不要帶整串網站名稱）、keywords 放主關鍵字、articleSection 放分類、author 用真實作者或編輯群，並連到組織。
- 組織資料要有名稱、網址、地址、聯絡方式、標誌。
- 每次大改內容就更新修改日期，排名好的舊文定期補新資訊。
- meta description 自己寫一段完整的話（約 80～120 字），包含主關鍵字和讀者能得到什麼；不要直接截內文第一句，尤其不能停在冒號。
- 有 FAQ 段落可以加 FAQPage 結構化資料；Google 目前大多數網站已不顯示 FAQ 摘要，主要幫助 AI 搜尋讀懂問答。
