# 去 AI 化檢查表

每封寫完逐條勾，有一條沒過就改。

## 口吻
- [ ] 讀起來像講者寫給一個人，不像公告或廣告。
- [ ] 至少一處用到講者在腳本裡的原句或慣用說法。
- [ ] 段落 1–3 句；一句只講一件事。
- [ ] 用具體情境（時間、地點、動作、對話）代替抽象形容。

## 刪掉這些
- 開場套話：「在這個快速變化的時代」「你是否曾經」「相信很多人都」。
- 收尾套話：「總而言之」「綜上所述」「希望對你有幫助」「讓我們一起」。
- 空泛動詞：「賦能」「打造」「助力」「深入探討」「全方位」「無縫」「解鎖」。
- 機械排比：連續三個「不只是…更是…」、每段都用「首先、其次、最後」。
- 假熱情：成串驚嘆號、大量 Emoji、「超級」「絕對」「保證」。
- 自我說明：「以下我將為你介紹」「這封信會告訴你」。

## 事實
- [ ] 每個數字、案例、引文都能在素材清單找到出處。
- [ ] 沒有自己編的優惠、期限、名額。
- [ ] 學員故事都已確認可公開。

## 中文（台灣）
- [ ] 台灣用詞（例：影片不是視頻、訊息不是信息、品質不是質量）。
- [ ] 全形標點；中英文之間不硬塞空格以外的符號。

## 最後一關
